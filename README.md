# باغ‌یار — نسخه جامع

سامانه یکپارچه مدیریت باغ با Next.js، Supabase و آماده استقرار روی Vercel.

## امکانات این نسخه
- داشبورد مدیریتی و KPIها
- چند باغ و مدیریت ساختار باغ
- قطعه، زیرقطعه، تقسیم و نگهداری رابطه تاریخی قطعات
- ساختار قطعه → ردیف → ستون/موقعیت → درخت
- شناسه یکتای درخت و وضعیت سلامت/خشک/حذف/جایگزینی
- نوع میوه و رقم به‌صورت موجودیت مستقل
- منابع آب: چاه، آب مستمر، تانکر و سایر منابع
- استخرها، ظرفیت، موجودی و حداقل موجودی
- گردش و مصرف آب
- عملیات انجام‌شده و عملیات برنامه‌ریزی‌شده
- یادآوری‌ها
- برداشت، کیفیت، مقصد و فروش
- هزینه‌ها و خلاصه سود ناخالص
- انبار و هشدار کمبود موجودی
- آفات و بیماری‌ها
- نیروی انسانی
- ماشین‌آلات و تجهیزات
- ثبت داده آب‌وهوا
- گزارش‌های مدیریتی
- تنظیمات، نوع میوه و رقم
- RLS برای جداسازی داده‌های کاربران

## نصب
```bash
npm install
npm run dev
```

## Supabase
1. در Supabase بخش SQL Editor را باز کنید.
2. migrationهای داخل `supabase/migrations/` را به‌ترتیب اجرا کنید:
   - `20261006160000_initial.sql`
   - `20261006170000_tree_grid.sql`
   - `20261006190000_complete_modules.sql`
3. در Vercel این متغیرها را قرار دهید:
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`

## استقرار روی Vercel
Repository را به Vercel وصل کنید و Framework را Next.js بگذارید. بعد از تنظیم Environment Variables، Deploy را بزنید.

## نکته مهم
این نسخه یک هسته کامل و یکپارچه برای تمام منوهای توافق‌شده است. اتصال سرویس‌های بیرونی مثل نقشه آنلاین، هواشناسی زنده، ماهواره، سنسورها، AI و خروجی‌های پیشرفته Excel/PDF در همین معماری قابل اضافه شدن است.
